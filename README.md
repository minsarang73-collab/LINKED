# LINKED · 인연 노트

앱 주소: **https://minsarang73-collab.github.io/LINKED/**

모임별로 만나는 사람을 정리하고, 만날 때마다 먹은 음식과 와인, 나눈 이야기, 주고받은 선물을 기록하는 휴대폰 앱입니다.

- **설치형 앱(PWA)**: 홈 화면에 추가하면 아이콘을 눌러 앱처럼 전체 화면으로 열려요. 인터넷이 없어도 열려요.
- **만남 전 체크**: 사람 화면에 지난번 챙길 것, 가족 이야기, 못 먹는 음식, 함께 마신 와인, 지난 선물, 생일이 자동으로 모여요. 무료이고 인터넷 없이도 돼요.
- **기록은 각자 휴대폰에만 저장**: 서버가 없어서 다른 사람이나 앱을 만든 사람도 기록을 볼 수 없어요. 이 주소를 다른 사람에게 알려 주면 그 사람은 자기 휴대폰에 따로 기록해요.
- **AI 기능(선택)**: 설정에서 본인의 Anthropic API 키를 넣으면 명함·와인 라벨 사진으로 빈칸을 자동으로 채울 수 있어요. 키가 없어도 나머지 기능은 모두 쓸 수 있어요.

## 설치하기

- **안드로이드 (Chrome)**: 앱 주소를 열고 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **삼성 인터넷**: ≡ → **현재 페이지 추가** → **홈 화면**
- **아이폰 (Safari)**: 공유 버튼(□↑) → **홈 화면에 추가**

## 백업

기록과 사진은 휴대폰 안에만 있어요. 휴대폰을 바꾸거나 앱·브라우저 데이터를 지우면 기록도 사라지니, **설정 → 백업**에서 가끔 백업 파일을 저장해 두세요. 새 휴대폰에서는 **백업 파일 불러오기**로 되살릴 수 있어요. API 키는 백업 파일에 들어가지 않아요.

## AI 기능 (선택)

1. [console.anthropic.com](https://console.anthropic.com)에 가입해요.
2. **API Keys**에서 키를 만들어요.
3. **Billing**에서 크레딧을 충전해요.
4. LINKED **설정 → AI 기능**에 키를 넣고 **연결 확인**을 누른 뒤 저장해요.

- 사용한 만큼 요금이 나가요. 명함·라벨 한 장에 대략 수십 원이에요.
- 키는 그 휴대폰 안에만 저장되고, AI를 쓸 때 Anthropic API로만 보내져요.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면, 저장, AI 호출) |
| `manifest.webmanifest` | 설치용 앱 정보 (이름, 아이콘, 색) |
| `sw.js` | 오프라인 실행을 위한 서비스 워커 |
| `vendor/anthropic-sdk-0.133.0.js` | Anthropic 공식 TypeScript SDK 0.133.0 (`@anthropic-ai/sdk`)을 브라우저용으로 묶은 파일 |
| `icons/` | 앱 아이콘 |

앱을 고친 뒤 배포할 때는 `sw.js`의 `CACHE` 이름과 `index.html`의 `APP_VERSION`을 함께 올려야, 설치된 앱이 새 버전을 받아요.
